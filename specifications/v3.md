# `.xff` specification v3

> [!note]
> ***This version is not yet finalized.***

## Musings about a future version 3

### Error correction
V2 added error detection, this would be the next logical step.

### Add version error detection
Some way to detect if the version of the file was corrupted.

- Just save the version twice?
- Add a checksum?
    - way too overkill, adding a checksum to a 1 byte value
- add versions to values? after the value marker, in front of the length of the value?
    - could allow 'mixing' of values from different versions also

### Change `Number` encoding
Add `Number` version 3 that accepts `Float` and `Integer` to encode them in binary directly?
Add `NaN` and `Infinity` as xff byte values? 14 & 15 would fit nicely.

### Change `String` encoding
Add `String` version 3 that accepts `UTF-8` and / or `UTF-16`?
